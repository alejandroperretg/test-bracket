# test-bracket

Parametric L-bracket in build123d: two 40 mm legs, 30 mm wide, 4 mm wall, one Ø5.5 mm (M5 clearance) hole per leg, 8 mm inner fillet. All six parameters live at the top of `bracket.py`.

## Project page

`docs/index.html` presents the part: an interactive 3D model, a first-angle drawing generated by hidden-line projection of the B-rep, a three-way volume check (hand calculation, B-rep, STL), the test results and a parameter explorer with a cantilever load estimate.

Open `docs/index.html` in a browser to view it locally (the 3D view loads three.js from a CDN, so it needs internet). To publish it with GitHub Pages, see `.github/workflows/pages.yml`.

## Commands

```
uv run python bracket.py      # build the part, export exports/bracket.step + .stl
uv run pytest                 # geometry tests
uv run python make_site.py    # all of the above, then regenerate docs/data.js
```

`make_site.py` reads everything from the model, so after changing a parameter the drawing, numbers and tests on the page update with one command.

## Layout

```
bracket.py          parameters, geometry, export
make_site.py        page data: views, mesh, checks, test results -> docs/data.js
tests/              pytest geometry checks
exports/            bracket.step (CAD), bracket.stl (printing)
docs/               the project page
```
